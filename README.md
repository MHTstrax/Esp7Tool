# Esp7Tool by MHT

Программа на Python для прошивки микроконтроллеров ESP32 и ESP8266. Работает на Windows 7 и Windows 10 (совместима с Python 3.8.10).

## Функционал:
- Автоматический поиск и обновление подключенных по USB COM-портов.
- Поддержка одновременной прошивки до 3-х бинарных файлов (.bin) по разным адресам памяти (загрузчик, разделы, приложение).
- Вывод полного лога утилиты esptool на экран в реальном времени.
- Работа в отдельном потоке (окно программы не зависает во время процесса записи).

## Установка зависимостей:
```bash
pip install esptool pyserial
```

## Запуск:
```bash
python main.py
```

## Инструкция:
1. Подключите плату к компьютеру и нажмите кнопку «Обновить».
2. Выберите нужный тип чипа из списка.
3. Отметьте галочкой строку, выберите файл прошивки и укажите HEX-адрес памяти (например, `0x1000` или `0x0`).
4. Нажмите кнопку «НАЧАТЬ ПРОШИВКУ».
