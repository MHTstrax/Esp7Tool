# Esp7Tool by MHT

Простая и легкая программа для прошивки плат ESP32 и ESP8266. Написана на Python специально для стабильной работы на компьютерах с Windows 7 и Windows 10. 

Интерфейс сделан в строгом, классическом стиле обычных системных утилит (никаких лишних цветов, анимаций и смайликов), чтобы всё работало быстро и не отвлекало от задачи.

## Что умеет программа:
- Искать подключенные платы по USB (автоматически находит нужный COM-порт).
- Шить как один файл, так и до трех файлов одновременно (например, если для вашей платы отдельно нужно залить загрузчик, таблицу разделов и саму прошивку).
- Работать на старых версиях Python (проверено на Python 3.8.10 для Windows 7).
- Не виснуть во время записи — лог прошивки выводится на экран в реальном времени.

## Как запустить из исходного кода

1. Установите две библиотеки для работы с платами и портами:
```bash
pip install esptool pyserial
```

2. Запустите программу командой:
```bash
python main.py
```

## Как пользоваться:
1. Вставьте плату в USB и нажмите кнопку «Обновить», чтобы программа увидела порт.
2. Выберите тип вашего чипа (ESP32 или ESP8266).
3. Поставьте галочку напротив нужной строки, выберите `.bin` файл прошивки через кнопку «Обзор...» и укажите адрес памяти (например, `0x1000`).
4. Выберите скорость (по умолчанию `115200`) и нажмите «НАЧАТЬ ПРОШИВКУ».
